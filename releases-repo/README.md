# Sarkhans Claude Starter

One app that turns your projects into an agentic development setup for **Claude Code**: an orchestrator that plans and delegates to specialist agents, strict quality, security, design and database rules, and a catalog of skills. It works with TypeScript/Next.js, Go, PHP (Laravel/Symfony), Python (Django/FastAPI) and Docker projects.

## Install

1. Open the downloaded file and drag **Sarkhans Claude Starter** into **Applications**.
   No admin rights on your Mac? Use the **Applications** folder inside your home folder instead (create it if it isn't there).
2. Open the app. The first time, macOS blocks it because it doesn't come from the App Store:
   - **macOS 15 or newer:** System Settings → Privacy & Security → scroll down → **Open Anyway**
   - **macOS 13–14:** right-click the app → **Open** → **Open**
3. Follow the setup screen: Node.js, Git, your projects folder and Claude's language. Each step has its own button.
4. Select your projects and press **Set up**.

You also need Claude Code: <https://docs.claude.com/en/docs/claude-code/overview>

## Updates

The app checks for new versions by itself. When one is available, an **Update** button appears in the app. Press it and the app updates and restarts; there's no need to download it again.
