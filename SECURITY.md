# Security

Please report a security problem privately: open a [security advisory](https://github.com/sarkhandigitech/sarkhans-claude-starter/security/advisories/new) instead of a public issue. Describe what you found and how to reproduce it. You'll get an answer as soon as possible.

The app is ad-hoc signed and not notarized by Apple. Download it only from this repository's [Releases](https://github.com/sarkhandigitech/sarkhans-claude-starter/releases) page or the project site, never from a mirror.
